# Compliance

SteadyRoute helps users route and diagnose local LLM requests. It does not provide provider accounts, guarantee free capacity, or grant permission to use any service outside its terms.

## Responsible Use

Use SteadyRoute only with providers and accounts you are authorized to use.

Do not:

- Resell provider access.
- Share your local router as a public service.
- Use the router to bypass limits, access controls, or eligibility rules.
- Misrepresent provider availability or quota state.

## Free-Tier Availability

Free-tier availability is controlled by providers and may change without notice. SteadyRoute can track catalog data, observe errors, and route around failures when possible, but it cannot guarantee free capacity.

## Catalog Data

Catalog entries should link to provider-facing documentation where possible. Unknown or uncertain data should be marked transparently instead of guessed.
